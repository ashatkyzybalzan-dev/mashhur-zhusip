# Мәшһүр Жүсіп AI — іске қосу нұсқаулығы

Бұл — Express сервері мен веб-интерфейсі бар AI чат. API кілті браузерге жіберілмейді, сервердің `.env` файлында сақталады.

## Жергілікті компьютерде іске қосу
1. Node.js 18 немесе жаңасын орнатыңыз.
2. Осы жоба бумасында терминал ашыңыз.
3. `npm install` командасын орындаңыз.
4. `.env.example` файлын `.env` деп көшіріңіз.
5. `.env` ішіне API параметрлерін жазыңыз. Groq мысалы:
   ```env
   API_BASE_URL=https://api.groq.com/openai/v1
   API_KEY=өз_API_кілтін_осында
   MODEL=llama-3.3-70b-versatile
   PORT=3000
   ```
6. `npm start` командасын орындаңыз.
7. Браузерде `http://localhost:3000` ашыңыз.

## Render арқылы жариялау
1. GitHub-та репозиторий ашып, жоба файлдарын жүктеңіз. `.env` файлын жүктемеңіз.
2. Render-де **New + → Web Service** таңдап, репозиторийді қосыңыз.
3. Root Directory бос қалсын (егер файлдар репозиторий түбірінде болса).
4. Build Command: `npm install`.
5. Start Command: `npm start`.
6. Render → Environment ішіне `API_BASE_URL`, `API_KEY`, `MODEL` айнымалыларын қосыңыз.
   - Groq: `API_BASE_URL=https://api.groq.com/openai/v1`
   - Модель: `llama-3.3-70b-versatile` (қолжетімді болмаса, провайдердегі қолжетімді модельді таңдаңыз)
7. Deploy аяқталғаннан кейін Render берген URL-ді ашыңыз.

OpenAI қолданғанда `API_BASE_URL=https://api.openai.com/v1` және өз аккаунтыңыз қолдайтын модель атауын енгізіңіз.

## Қауіпсіздік
- `.env` файлын GitHub-қа жүктемеңіз.
- API кілтін HTML немесе JavaScript ішіне жазбаңыз.
- Кілт жарияланып кетсе, провайдер кабинетінде оны дереу ауыстырыңыз.
- AI берген тарихи мәліметтерді ғылыми жұмыста қолданар алдында сенімді дереккөздермен тексеріңіз.

## Ескертулер
- Бұл бастапқы жұмыс нұсқасы: қолданушылар базасы және серверде чат тарихын сақтау жоқ.
- AI API қолдану провайдердің тарифіне/лимитіне байланысты болуы мүмкін.
